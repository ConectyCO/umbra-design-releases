# UMBRA Design: releases

Instaladores de UMBRA Design. El código fuente está en un repositorio privado.

**Descargar:** [última versión](https://github.com/ConectyCO/umbra-design-releases/releases/latest). Descarga `UmbraDesign-Setup-<versión>.exe` y ejecútalo.

- Se instala solo para tu usuario (Windows 10/11) y no pide permisos de administrador.
- Si Windows muestra *"Windows protegió su PC"*, haz clic en **Más información → Ejecutar de todas formas**. Solo pasa en la primera instalación.
- La app se actualiza sola desde esta página.
- Para conectar Claude Code o Codex: **Ajustes → Agents → Connect**.
